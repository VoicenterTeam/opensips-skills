## `append_branch([uri], [qvalue])`

Extends destination set by a new entry. Without parameter, copies the current URI. With a parameter, copies the URI in the parameter. Not possible in on_failure_route if 6XX received.

**Parameters:**

- `qvalue` *(string, optional)* — The Q value for the new branch.
- `uri` *(string, optional)* — The URI to append as a new branch.

**Usable from:** request_route, failure_route

**Example.** Appends current URI to branches and modifies RURI..

```opensips.cfg
if ($rm=="INVITE" && $ru=~"sip:B@xx.xxx.xx ")
{
    append_branch();
    seturi("sip:C@domain");
    t_relay();
    exit;
};
```

**Example.** Appends a specific URI to branches..

```opensips.cfg
if(method=="INVITE" && uri=~"sip:B@xx.xxx.xx ") {
    append_branch("sip:user@domain");
    t_relay();
    exit;
}
```

## `assert(expression, [message])`

Only works if enable_asserts is set to true. If the given expression evaluates to false, script execution is stopped and the error_route is executed. If abort_on_assert is enabled, OpenSIPS will also shutdown.

**Parameters:**

- `expression` *(string, required)* — The expression to evaluate.
- `message` *(string, optional)* — Optional message to log on failure.

**Usable from:** all_routes

**Example.** Asserts that the User-Agent is not friendly-scanner..

```opensips.cfg
assert($ua != "friendly-scanner", "Forbidden UA: \"friendly-scanner\"");
```

## `drop()`

       xlog("L_INFO","removing branch $var(i) with URI=[$(branch(uri)[$var(i)])]\n");

       $var(i) = $var(i) + 1;
   }
