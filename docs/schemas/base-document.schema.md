# Base Document Schema

The `BaseDocument` is the parent schema that all other document types extend. It contains the common metadata required for every piece of documentation.

## Schema Definition

```typescript
interface BaseDocument {
  id: string;               // Unique ID (e.g., "module-dialog-3.6")
  document_type: DocType;   // Enum of all document types
  version: string;          // OpenSIPS version (e.g., "3.6")
  title: string;            // Document title
  url: string;              // Original URL
  content_markdown: string; // Full raw content converted to Markdown
  content_html?: string;    // Optional: Original HTML for debugging
  category: string;         // Primary category (e.g., "Modules", "Core")
  section?: string;         // Secondary category/section
  synopsis?: string;        // Brief 2-3 sentence summary
  keywords?: string[];      // Array of search keywords
  related_documents?: string[]; // IDs of related documents
  last_updated?: string;    // ISO Date of last upstream update
  extracted_at: string;     // ISO Date of extraction
}
```

## Field Details

| Field | Required | Description |
|-------|----------|-------------|
| `id` | Yes | A deterministic ID generated from the type, name, and version. Pattern: `{type}-{name}-{version}`. Example: `module-tm-3.6`. |
| `document_type` | Yes | Must be one of the valid `DocType` enum values. |
| `version` | Yes | The MAJOR.MINOR version string. |
| `title` | Yes | Clean title of the document. |
| `url` | Yes | The source URL where this data was extracted from. |
| `content_markdown` | Yes | The full body content processed through Turndown. |
| `content_html` | No | Retained only if debugging is enabled. |
| `synopsis` | No | Generated by LLM if not present in source. |
| `keywords` | No | Generated by LLM for better searchability. |
